# Xi intercepted AI exchange

The Xi pre-scene is staged as a live interception inside the Red Command room, not as a full-screen chat transcript. The room remains visible beneath the surveillance layer while three speaker cards establish the dramatic hierarchy:

- DeepSick: a cheerful state model whose visual friendliness is part of the censorship mechanism;
- Xi: the local control authority directing both channels;
- C.L.A.U.D.I.A.: an external model whose expression changes on selected sarcastic replies.

Only one message is visually dominant at a time. Previous lines collapse into a three-entry intercept buffer, preventing the scene from turning into a wall of text. Signal lines, packet count, scanline movement, portrait emphasis, and channel lighting communicate the active exchange.
